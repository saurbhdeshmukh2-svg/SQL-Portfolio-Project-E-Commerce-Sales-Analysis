# SQL-Portfolio-Project-E-Commerce-Sales-Analysis

This project simulates a real-world E-Commerce business database using SQL. The database consists of multiple interconnected tables with Primary Key and Foreign Key relationships, enabling comprehensive sales and customer analysis.

## Database Schema

The project contains the following tables:

* Customers
* Products
* Orders
* Order Details
* Payments

These tables are linked using relational database concepts to support advanced SQL queries and business analysis.

## Key Features

* Relational Database Design
* Primary & Foreign Key Relationships
* Customer Analysis
* Product Performance Analysis
* Sales & Revenue Tracking
* Payment Analysis
* Business KPI Reporting
* SQL Joins
* Aggregate Functions
* Subqueries
* Window Functions
* CTEs (Common Table Expressions)

## Business KPIs Analyzed

* Total Revenue
* Total Orders
* Average Order Value
* Top Customers by Revenue
* Top Selling Products
* Revenue by Category
* Revenue by City
* Payment Method Analysis
* Customer Lifetime Value (CLV)
* Sales Trends

## SQL Concepts Used

* INNER JOIN
* LEFT JOIN
* GROUP BY
* HAVING
* ORDER BY
* Subqueries
* Correlated Subqueries
* Window Functions
* RANK()
* DENSE_RANK()
* CTEs

This project demonstrates practical SQL skills required for Data Analyst and Business Analyst roles by solving real-world business problems and generating actionable insights from sales data.
